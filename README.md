# Daydeck 약관 및 정책

일정·할 일·가계부를 한 곳에서 관리하는 앱 **Daydeck**의 법적 고지 문서를 공개하는
저장소입니다. 앱 소스 코드는 여기 없습니다.

- [개인정보처리방침](https://junnuu9-wq.github.io/daydeck-legal/privacy_policy.html)
- [이용약관](https://junnuu9-wq.github.io/daydeck-legal/terms_of_service.html)

## 이 저장소가 따로 있는 이유

앱 스토어(Google Play·App Store)는 심사 과정에서 **로그인 없이 접근 가능한**
개인정보처리방침 URL을 요구합니다. 앱 저장소는 비공개라 GitHub Pages를 무료로
쓸 수 없어서, 공개해도 되는 문서만 이곳으로 분리했습니다.

문서를 고칠 때는 이 저장소의 HTML을 수정하면 됩니다. 주소가 바뀌지 않으므로
앱이나 Play Console 설정을 다시 건드릴 필요가 없습니다.
